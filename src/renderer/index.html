Connect to Jira

Track time here and it lands in your Jira worklogs.

First, get an API token
  1. Click Get API token — Atlassian opens in your browser.
  2. Click Create API token, name it (e.g. “Time Tracker”), then Copy it.
  3. Click the ⏱ in the menu bar to come back, and paste it below.

Your token is encrypted in your Mac’s Keychain and is only ever sent to your Jira site.
